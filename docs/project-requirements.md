# 專案需求說明

## 主要使用者

- 遠東商銀主管及信用卡業務分析人員。

## 使用情境

1. 開啟網站快速掌握最新信用卡市場狀況。
2. 查看遠東商銀的規模、排名、市占率與成長表現。
3. 比較遠東商銀與主要同業的差距及趨勢。
4. 在會議中快速查找可直接引用的數據。
5. 深入查看各銀行、月份及指標的原始數值。

## 預計功能

1. 市場總覽。
2. 遠銀市場定位。
3. 同業比較。
4. 歷史趨勢。
5. 明細查詢。
6. 月報重點摘要。
7. 未來新增每月資料時可重複執行更新流程。

## 目前仍待確認

1. 原始附表五的實際檔案格式與欄位。
2. 第一版要納入的資料期間。
3. 主要比較同業名單。
4. 各指標的正式計算公式。
5. 網站發布方式與存取權限。
